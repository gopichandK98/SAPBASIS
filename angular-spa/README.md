# SAP Learning Hub

A standalone Angular SPA for exploring a practical SAP technical learning roadmap, SAP business modules, and HANA administration topics.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

From this directory:

```sh
npm install
npm start
```

Open the local URL printed by Angular CLI (usually `http://localhost:4200`).

## Production build

```sh
npm run build
```

The production bundle is written to `dist/sap-learning-hub`.

## Features

- Overview dashboard with a seven-stage learning roadmap
- Roadmap completion controls and live progress indicator
- Searchable SAP module cards
- HANA administration learning track
- Responsive layout for desktop and mobile
